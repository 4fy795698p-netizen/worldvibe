WorldVibe Information

WorldVibe is a social media application. Users are responsible for the content they upload. Do not upload illegal, abusive, copyrighted or harmful material.

The current launch version uses Firebase for authentication, database and media storage. Privacy controls shown in the application must be backed by production Firestore/Storage security rules before being treated as a complete security boundary.
